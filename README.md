# Fruit Image Classifier

A CNN-based fruit image classification project built using Python and TensorFlow.

## Technologies
- Python
- TensorFlow
- NumPy
- Matplotlib

## Features
- Image preprocessing
- Data augmentation
- CNN model training
- Fruit image classification

## Dataset Classes
- Apple
- Banana
- Lime
- Orange

## Result
The CNN model achieved approximately 90% accuracy on the fruit image dataset.
